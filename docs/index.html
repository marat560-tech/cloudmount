Работает как обычный диск

Не нужно ничего синхронизировать: файлы подгружаются по мере открытия.

1

Своя буква для каждого облака

Диски видны в «Этом компьютере» под вашими названиями и со своими значками.

2

Видео без полной закачки

Большие файлы читаются частями — фильм начинает играть сразу.

3

Ничего не теряется

Если связь пропала, изменения сохраняются на компьютере и догружаются потом.

4

Пароли под защитой Windows

Ключи и токены зашифрованы: прочитать их может только ваша учётная запись.

5

Трей, автозапуск, тёмная тема

Запускается вместе с Windows, сворачивается в трей, выглядит как Windows 11.

6

Открытый исходный код

Весь код на GitHub под лицензией GNU GPL v3 — можно проверить, что программа делает с вашими файлами.

Для зашифрованных данных

Контейнеры VeraCrypt прямо в облаке

Большие файлы — контейнеры, образы дисков, виртуальные машины — отправляются в облако один раз, когда вы их закрываете, а не при каждом сохранении. Пока контейнер открыт, работа идёт с локальной скоростью.

Если компьютер выключился до конца загрузки, изменения не пропадут: они догрузятся автоматически.

  1. 1Подключите контейнер в VeraCrypt с облачного диска — при первом изменении он один раз скачается.
  2. 2Работайте с файлами внутри как обычно — быстро, без ожидания сети.
  3. 3Отключите контейнер — CloudMount загрузит его в облако и покажет прогресс.

Частые вопросы

Это бесплатно?

Да, полностью: ни подписок, ни ограничений на число дисков.

Файлы скачиваются на компьютер целиком?

Нет. Список файлов и их содержимое подгружаются по мере открытия. Место занимают только файлы, с которыми вы сейчас работаете.

Зачем создавать «своё приложение» у Яндекса, Google, Dropbox и других?

Эти сервисы выдают доступ к API только зарегистрированным приложениям. Своё приложение делается за пару минут, и ваш доступ не зависит ни от кого другого. В окне настройки каждого облака есть подсказки и ссылки.

Почему Windows предупреждает о неизвестном издателе?

У программы нет платной цифровой подписи. Код открыт, а exe собирается автоматически на GitHub из этого кода.

Можно подключить Облако Mail.ru?

Да, но Mail.ru даёт доступ по WebDAV только на платных тарифах и требует отдельный пароль для внешнего приложения.

А TeraBox?

У TeraBox нет официального API, поэтому встроенной поддержки нет. Его можно подключить через бесплатную программу AList, которая отдаёт TeraBox по WebDAV, — инструкция в README. Способ неофициальный и может перестать работать.

Безопасно ли хранить там контейнеры VeraCrypt?

Да: контейнер шифруется на вашем компьютере, облако видит только зашифрованный файл. Не открывайте один контейнер одновременно с двух компьютеров.
