## CloudMount 2.0.3

- Облако Билайн и другие WebDAV-серверы, которые не сообщают размер: занятое место
  теперь считается по файлам (в фоне, раз в час). Объём облака укажите один раз в
  настройках диска — поле «Размер диска, ГБ».
- Размер диска виден в Проводнике сразу после подключения.
- Старые имена дисков вида `yandex-a7872ea34122` убираются из Проводника.

Скачайте **`CloudMount-Setup.exe`** — установщик сам поставит драйвер WinFsp.
