# CloudMount — облака как диски Windows (аналог RaiDrive)

Подключает **Яндекс Диск, Облако Билайн, Dropbox, Google Drive** и любой **WebDAV**
как обычные диски с буквой (например, `Y:`). Работает в Проводнике и в любой программе.

## Установка

1. Установите драйвер **WinFsp** (бесплатный): https://winfsp.dev/rel/ — при установке
   оставьте компоненты «Core» и «Network Provider» (нужен для вида «сетевой диск»).
2. Скачайте **CloudMount.exe** со страницы
   [Releases](https://github.com/marat560-tech/cloudmount/releases/latest) и запустите.
   Python не нужен.

Windows может предупредить «Неизвестный издатель» (у exe нет платной цифровой подписи):
«Подробнее» → «Выполнить в любом случае».

<details><summary>Запуск из исходников / своя сборка</summary>

- Python 3.10+ с python.org (галочка «Add python.exe to PATH»), затем `run.bat`.
- Свой exe: `build.bat` → `dist\CloudMount.exe`.
- Каждый push в `main` собирает exe автоматически (вкладка Actions → артефакт CloudMount),
  а тег `v*` публикует его в Releases.
</details>

## Подключение облаков

В окне нажмите **«Добавить»**, выберите облако, букву диска и заполните поля.
Кнопка **«Проверить»** покажет, работает ли подключение.

### Облако Билайн
1. Зайдите на cloudbeeline.ru → «Профиль и настройки» → «Безопасность».
2. Включите **«Доступ через WebDAV»** — там будут логин (номер телефона) и пароль.
3. Введите их в CloudMount.

### Яндекс Диск
Яндекс тормозит свой WebDAV, поэтому программа работает через быстрый REST API.
Для него нужно один раз зарегистрировать своё приложение:
1. https://oauth.yandex.ru/client/new → платформа «Веб-сервисы».
2. Redirect URI: `http://127.0.0.1:53682/`
3. Доступы: **Яндекс Диск REST API** → «Чтение всего Диска», «Запись в любом месте на Диске»,
   «Доступ к информации о Диске».
4. Скопируйте ClientID и Client secret в CloudMount → «Войти через браузер».

### Dropbox
1. https://www.dropbox.com/developers/apps → Create app → Scoped access → **Full Dropbox**.
2. Вкладка Permissions: `files.metadata.read/write`, `files.content.read/write` → Submit.
3. Вкладка Settings → OAuth 2 → Redirect URIs: `http://127.0.0.1:53682/`
4. Скопируйте **App key** в CloudMount → «Войти через браузер».

### Google Drive
1. https://console.cloud.google.com → создайте проект → «APIs & Services» → включите **Google Drive API**.
2. «OAuth consent screen» → External → добавьте свой email в **Test users**.
3. «Credentials» → Create credentials → OAuth client ID → тип **Desktop app**.
4. Скопируйте Client ID и Client secret в CloudMount → «Войти через браузер».

> Пока приложение Google в режиме «Testing», токен живёт 7 дней — потом просто нажмите
> «Изменить» → «Войти через браузер». Чтобы не было ограничения, опубликуйте приложение
> (Publish app) — для личного пользования проверка Google не обязательна.

### Другой WebDAV
Nextcloud, Облако Mail.ru (платные тарифы), `https://webdav.yandex.ru` и т. д. — адрес, логин, пароль.

## Как это устроено

- Каждый диск — отдельный процесс (`CloudMount.exe --mount <id>`): зависание одного облака
  не трогает остальные.
- Список файлов кэшируется на 60 секунд, поэтому Проводник работает быстро.
  Изменения, сделанные на другом устройстве, появятся в течение минуты.
- Файлы до 8 МБ скачиваются целиком, большие читаются кусками по 4 МБ —
  видео и архивы открываются сразу, без полной закачки.
- При записи файл собирается во временной папке и отправляется в облако при закрытии.
  Если загрузка не удалась, изменения остаются в кэше и догружаются при следующем подключении.
- Удалённые файлы попадают в корзину облака (Яндекс, Google, Dropbox), их можно восстановить.
- Пароли и токены зашифрованы Windows DPAPI: расшифровать их может только ваша
  учётная запись Windows на этом компьютере. Настройки: `%APPDATA%\CloudMount\config.json`.
- Журналы: кнопка «Журнал» или `%LOCALAPPDATA%\CloudMount\logs`.

## Контейнеры VeraCrypt и другие большие файлы

Файлы от 64 МБ (контейнеры VeraCrypt, образы дисков, виртуальные машины) отправляются
в облако **только при закрытии**, а не при каждом сохранении. Порядок работы:

1. Подключите контейнер в VeraCrypt с облачного диска — при первом изменении он один раз
   скачается в кэш, дальше работа идёт с локальной скоростью.
2. Закончили — **отключите контейнер в VeraCrypt**. В этот момент он целиком загрузится
   в облако; в окне CloudMount видно «загрузка … NN%».
3. Не выключайте компьютер, пока загрузка не дойдёт до 100%.

Если всё же выключили или программа упала — изменения не пропадут: они лежат в
`%LOCALAPPDATA%\CloudMount\cache` и догрузятся автоматически при следующем подключении.
При выходе из программы и при «Отключить» CloudMount сначала отправляет изменения
и только потом отключает диск.

Советы: держите контейнеры небольшими (для бесплатного Яндекса — до 1 ГБ: это лимит
размера файла), один контейнер не открывайте одновременно с двух компьютеров.
Режим можно выключить в настройках диска.

## О программе и поддержка

Кнопка «О программе» в окне (или пункт в меню значка в трее) — версия, ссылка на
GitHub и реквизиты, если хотите поддержать автора.

## Ограничения

- Документы Google (Docs/Sheets/Slides) не показываются: у них нет файла для скачивания.
- Нельзя открыть один и тот же файл на запись одновременно с двух компьютеров:
  сохранится версия того, кто закрыл файл последним.
- Скорость ограничена самим облаком (у Билайна заметно ниже, чем у остальных).

## Если не работает

| Симптом | Что делать |
|---|---|
| «не установлен WinFsp» | Установите WinFsp и перезапустите программу |
| «нет связи с облаком или ошибка входа» | «Изменить» → «Проверить»; для OAuth — «Войти через браузер» заново |
| «не удалось создать диск» | Выберите другую букву диска; снимите галочку «как сетевой диск» |
| Порт 53682 занят при входе | Закройте rclone или другую программу, которая его использует |

## Структура

```
main.py                    точка входа
cloudmount/fs.py           виртуальная файловая система (FUSE/WinFsp), кэш
cloudmount/providers/      yandex.py, webdav.py (Билайн), dropbox.py, gdrive.py
cloudmount/oauth.py        вход через браузер
cloudmount/config.py       настройки, шифрование DPAPI
cloudmount/mount.py        процесс одного диска
cloudmount/gui.py          окно и значок в трее
cloudmount/about.py        «О программе» и реквизиты для поддержки
tests/                     тесты (python -m pytest tests)
```
